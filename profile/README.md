# CMCLauncher

**A modern, open-source Minecraft launcher ecosystem.**

Welcome to **CMCLauncher-Dev**, the home of CMCLauncher and its related projects.

We aim to provide a simple, modern, and customizable Minecraft experience across desktop and mobile platforms.

## 🚀 Our Projects

### 🖥️ CMCLauncher

A modern Minecraft: Java Edition launcher for Windows, built with **C# and WinUI 3**.

**Features:**
- Native Windows experience
- Minecraft version management and launching
- Mod and community resource management
- Customizable themes and appearance
- Clean and modern user interface

**[View Repository](https://github.com/CMCLauncher-Dev/CMCLauncher)**

### 📱 CMCLauncher PE

A mobile Minecraft launcher that brings **Minecraft: Java Edition to mobile devices**.

Enjoy Minecraft Java Edition on your phone with a launcher designed for mobile use.

**[View Repository](https://github.com/CMCLauncher-Dev/CMCLauncher-PE)**

## 🗺️ Roadmap

We're continuously improving our projects and exploring new possibilities.

- **Windows** — Native desktop launcher
- **Linux** — Cross-platform desktop support
- **macOS** — Planned desktop support
- **Mobile** — Minecraft Java Edition through CMCLauncher PE
